# 知识库

具身智能 / 机器人学习方向的知识库：按「**模块 → 子方向 → 细分方向**」三级组织，逐层沉淀方法脉络与论文。

## 模块

| 模块 | 内容 | Summary |
|---|---|---|
| 1 | **VLA**（视觉-语言-动作模型） | [VLA 模块](1-vla/index.md) |
| 2 | **世界模型** | [世界模型模块](2-world-model/index.md) |
| 3 | **强化学习** | [强化学习模块](3-rl/index.md) |

## 组织约定

**每个模块目录**下：

| 内容 | 说明 |
|---|---|
| `index.md` | 模块 Summary，汇总本模块各子方向的方法 |
| `1-xxx/`、`2-xxx/` | 每个子目录对应一个**子方向** |

**每个子方向目录**下：

| 内容 | 说明 |
|---|---|
| `index.md` | 子方向 Summary |
| `1-xxx/`、`2-xxx/` | 更**细分方向** |
| `papers/` | 本方向**论文源文件**（PDF / 笔记 / 代码梳理） |

## 怎么用

- 左侧导航由目录结构自动生成，目录名前缀 `1-`、`2-` 控制同级顺序；
- 页面之间用**相对路径**互跳，例如 `[VLA 模块](1-vla/index.md)`；
- 顶部搜索支持中文全文检索。

## 新增内容

1. 在对应层级新建目录，用 `序号-英文短名` 命名；
2. 目录内写 `index.md`，一级标题即导航标题；
3. 回到上一层 `index.md`，在表格里补一行链接。
