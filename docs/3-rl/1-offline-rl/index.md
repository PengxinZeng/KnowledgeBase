# 离线强化学习

**定位**：只给定一个固定的交互数据集，不与环境在线交互，学习策略或值函数。机器人场景下数据昂贵，离线 RL 是主流路线之一。

## 细分方向

| 细分方向 | 一句话概述 |
|---|---|
| [基于值函数](1-value-based/index.md) | 学 Q 函数，再做策略提取 |
| 序列建模 | 把轨迹当序列，用 Transformer 直接建模（Decision Transformer 一类） |

> 第二个细分方向为占位示例，尚未建目录。
