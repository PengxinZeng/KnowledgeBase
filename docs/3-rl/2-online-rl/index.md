# 在线强化学习

**定位**：策略与环境持续交互、用新采集的数据不断更新，数据分布随策略演化（非平稳）。真实机器人上受限于样本效率与安全性，常见做法是先在仿真里训。

## 细分方向

| 细分方向 | 一句话概述 |
|---|---|
| [策略梯度](1-policy-gradient/index.md) | 直接对策略参数求梯度，最大化期望回报 |
| 基于模型的在线 RL | 用世界模型生成想象轨迹，降低真实交互量 |

> 第二个细分方向为占位示例，尚未建目录。
